# Contributing

DinkusKit Commerce is developed in focused pull requests.

1. Start from current `main` on a dedicated branch.
2. Keep one product or infrastructure slice per pull request.
3. Add or update tests for observable behavior.
4. Run `npm test` and `npm run audit:repo`.
5. State scope, proof, and explicit non-goals in the pull request.

Never include real customer, tenant, credential, payment, inventory, or
production data in issues, tests, fixtures, logs, screenshots, or proof.
