**Does this build my storefront automatically?**

No. Commerce provides product, checkout and order behavior; your site provides the shop pages. [Try the demo store](https://playground.dinkuskit.com) to see a storefront using DinkusKit.

**Do I need every DinkusKit plugin?**

[Payments](https://dinkuskit.com/docs/reference/payments) supplies the payment connection. [Ship](https://dinkuskit.com/docs/reference/ship) is optional for testing labels; orders can be marked shipped by hand. Inventory and coupon checkout are not available in the current Registry build.

**Does a test order mean my store can accept live payments?**

No. Test and live readiness are separate. Follow the current [setup guide](https://dinkuskit.com/start) and verify your store's live connection before launching.

**Where should developers start?**

Read the [integration guide](https://dinkuskit.com/docs/developers/integrate), inspect the [source](https://github.com/dinkuskit/commerce), or [join the DinkusKit community](https://discord.gg/7yHZGj8p88).
