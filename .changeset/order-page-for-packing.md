Lay out the Orders detail page like WooCommerce's and Shopify's order screens. The order number, paid time and status, and a Test order warning come first. Then Ship to (with Correct address) sits beside Customer and Bill to, as parcel lines. Below that, an "N items ready to ship" line carries Create shipping label or Complete order, followed by an items table with frozen choices, price, quantity and line total, the payment summary (items subtotal, coupon, shipping, order total), and an Order record fold with the IDs. Amounts on the Orders pages read as dollars (`$80.00`), payment reads Paid or Nothing to pay, and times read in UTC. Block Kit only; the agent orders API is unchanged.
